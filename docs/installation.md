\# Installation



Planetary\_Atlas requires Python 3.10+ and a few scientific libraries.



\## 1. Clone the Repository



git clone https://github.com/RadioJupiter/Planetary\_Atlas.git

cd Planetary\_atlas



\## 2. Install Dependencies



pip install -r requirements.txt



If you do not have a `requirements.txt` yet, typical dependencies include:



numpy

matplotlib

scipy




\## 3. Run the Quickstart Notebook



jupyter notebook docs/QuickStart.ipynb





\## 4. Run the Example Script



python run\_atlast.py





You should see candidate radii and a hydro simulation plan printed to the console.
