# Planetary_Atlas Overview

Planetary_Atlas is a physics-driven toolkit for analyzing protoplanetary disks, identifying ring-forming mechanisms, and locating hidden planet candidates.

## Components
- **DiskAtlas** — loads disk physics and provides analysis tables.
- **planet_finder.py** — ranks radii by planet-like signatures.
- **hydro_planner.py** — prioritizes radii for hydro simulations.

## Goals
- Provide a clean, modular scientific workflow.
- Support observers and theorists studying disk structure.
- Offer reproducible analysis tools for ALMA disk data.
