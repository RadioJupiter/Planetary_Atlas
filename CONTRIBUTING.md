 # Contributing to Planetary_Atlas

Thank you for your interest in contributing!

## How to Contribute
- Open an issue describing your idea or bug.
- Fork the repository.
- Create a feature branch.
- Submit a pull request.

## Code Style
- Keep physics logic in `atlas/`.
- Keep analysis tools in `tools/`.
- Keep documentation in `docs/`.

## Testing
Add small, isolated tests for new functions.
